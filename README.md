# 🐦 Классификация видов птиц CUB-200-2011 с ResNet18

> Проектный практикум МИФИ 2025
> **Автор:** Сергей Смирнов

---

## 📌 Описание проекта

Цель проекта — разработка прототипа системы автоматической классификации видов птиц по изображениям с использованием предобученных моделей компьютерного зрения.

В работе используется датасет **CUB-200-2011**, содержащий:

* 🐦 **200 классов птиц**
* 🖼️ Более **6000 изображений**

---

## 🚀 Возможности модели

Модель решает следующие задачи:

* классификация вида птицы по изображению;
* вычисление **Top-1** и **Top-5** вероятностей;
* анализ ошибок через **confusion matrix**;
* визуализация предсказаний;
* обучение модели с progress bar.

---

## 🌍 Потенциальные применения

Прототип может использоваться в системах мониторинга экосистем:

* наблюдение за биоразнообразием;
* оценка динамики популяций;
* автоматическая обработка данных с фотоловушек и камер наблюдения.

# 🧠 Используемая модель

В проекте применяется предобученная модель:

* **ResNet18 (ImageNet pretrained)**

## ⚙️ Используемые оптимизации

* заморозка всех слоёв кроме последнего (*feature extractor*);
* fine-tuning последнего полносвязного слоя под 200 классов;
* ускоренное обучение на подвыборке;
* аугментации изображений (`RandomHorizontalFlip`);
* нормализация под стандарты ImageNet;
* вычисление метрик **Top-1** и **Top-5 accuracy**.
